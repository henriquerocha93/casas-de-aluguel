Sincronização na Nuvem (Supabase)

Por que usar o Banco na Nuvem?

Atualmente, seus dados são salvos apenas neste navegador (LocalStorage). Se você limpar os dados de navegação ou mudar de dispositivo, poderá perder suas informações. Conectando a uma nuvem Supabase gratuita:

  • Seus dados de inquilinos e pagamentos ficam guardados em segurança online.
  • Você pode acessar o painel de qualquer computador ou celular em tempo real.
  • Migração Automática: Seus dados locais existentes serão enviados automaticamente ao conectar!

Tutorial Rápido: Como Configurar em 2 Minutos

  1. Crie uma conta gratuita em supabase.com e crie um projeto chamado Casas de Aluguel.
  2. No painel do Supabase, vá em SQL Editor, clique em New Query, cole o código abaixo e clique em Run:
-- 1. Tabela de Imóveis
create table if not exists public.lumina_houses (
    id text primary key,
    number text not null,
    tenant text not null,
    phone text not null,
    due_day integer not null,
    start_date text not null,
    rent_value numeric not null,
    penalty_pct numeric default 2.00,
    interest_pct numeric default 0.33,
    payments jsonb default '[]'::jsonb,
    updated_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 2. Tabela de Usuários do Sistema
create table if not exists public.lumina_users (
    id text primary key,
    username text unique not null,
    password text not null,
    name text not null,
    updated_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 3. Inserir Usuário Administrador Inicial
insert into public.lumina_users (id, username, password, name)
values ('admin_root', 'admin', 'admin', 'Administrador')
on conflict (username) do nothing;
  1. Vá nas configurações do seu projeto Supabase (ícone de engrenagem) em API.
  2. Copie o campo Project URL e cole em "URL do Supabase" acima.
  3. Copie a chave Project API anon key (chave pública) e cole em "Chave Pública Anon" acima, depois clique no botão de Conectar!
